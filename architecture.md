## 2. Component Boundaries & Responsibilities

### RAG Retrieval Pipeline (`backend/app/rag/`)
1. **Ingestion**: `ingest.py` parses markdown transcripts, extracts YAML frontmatter metadata, splits text into ~600 character chunks with 100 character overlap, generates embeddings, and saves into PostgreSQL.
2. **Retriever**: `retriever.py` computes hybrid vector + keyword similarity scores against user query and returns top `k` chunks with guest name, title, date, URL, and snippet. Enforces similarity threshold to reject irrelevant queries.

### Agent Router (`backend/app/agents/`)
Classifies incoming user intent into 4 routes:
- `KNOWLEDGE_QNA`: Product management questions -> RAG retrieval -> Grounded Answer.
- `SHIP30_ESSAY`: Requests for Ship 30 essay -> RAG retrieval -> `Ship30Skill` (~1,250 words, hook, narrative, takeaways).
- `ARTIFACT_GEN`: Requests for HTML/MD layout -> RAG retrieval -> `ArtifactGeneratorSkill`.
- `DIRECT`: Chit-chat -> Direct assistant response.

### LLM Provider Abstraction (`backend/app/services/llm/`)
Abstract `BaseLLMProvider` interface implemented by `OllamaProvider`, `AnthropicProvider`, and `OpenAIProvider`.
The `LLMFactory` provides:
- Active provider getter/setter.
- Health check pinging.
- Failover generation logic: If requested primary provider fails, automatically attempts healthy fallback providers before raising an error.

### Security Model (`backend/app/services/security.py`)
- HTML artifacts generated by AI are treated as untrusted input.
- Rendered inside `iframe` with `sandbox="allow-scripts"` (strictly excluding `allow-same-origin` to isolate localStorage, cookies, and parent DOM access).
- Injects Content Security Policy (CSP) meta header restricting unauthorized external script sourcing.

## 3. Database Schema Definitions

```sql
CREATE TABLE sessions (
    id VARCHAR(36) PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE messages (
    id VARCHAR(36) PRIMARY KEY,
    session_id VARCHAR(36) REFERENCES sessions(id) ON DELETE CASCADE,
    role VARCHAR(20) NOT NULL,
    content TEXT NOT NULL,
    sources JSONB NULL,
    agent_route VARCHAR(50) NULL,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE artifacts (
    id VARCHAR(36) PRIMARY KEY,
    session_id VARCHAR(36) REFERENCES sessions(id) ON DELETE CASCADE,
    message_id VARCHAR(36) REFERENCES messages(id) ON DELETE CASCADE,
    artifact_type VARCHAR(20) NOT NULL,
    title VARCHAR(255) NOT NULL,
    content TEXT NOT NULL,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE transcript_chunks (
    id VARCHAR(36) PRIMARY KEY,
    guest VARCHAR(255) NOT NULL,
    title VARCHAR(500) NOT NULL,
    url VARCHAR(500) NULL,
    date VARCHAR(50) NULL,
    chunk_index INTEGER NOT NULL,
    content TEXT NOT NULL,
    embedding JSONB NULL,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```
